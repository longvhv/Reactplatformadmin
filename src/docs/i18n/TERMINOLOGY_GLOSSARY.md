### Bad Examples ❌

```typescript
// ❌ Too formal
deleteConfirm: 'Quý khách có chắc chắn muốn thực hiện thao tác xóa?',
// ✅ Better
deleteConfirm: 'Bạn có chắc chắn muốn xóa?',

// ❌ Too wordy
save: 'Nhấn vào đây để lưu lại thay đổi',
// ✅ Better
save: 'Lưu',

// ❌ Inconsistent terminology
user: 'Người sử dụng',  // Wrong
user: 'User',           // Wrong
// ✅ Better
user: 'Người dùng',     // Correct

// ❌ Translating technical terms
api: 'Giao diện lập trình ứng dụng',  // Too verbose
// ✅ Better
api: 'API',  // Keep original
```

## 🎯 TONE & STYLE GUIDE

### General Principles
1. **Simple & Clear**: Dùng từ ngắn gọn, dễ hiểu
2. **Friendly**: Dùng "bạn" thay vì "quý khách"
3. **Action-oriented**: Động từ rõ ràng, trực tiếp
4. **Consistent**: Giữ nhất quán thuật ngữ

### Button Text
```typescript
// Use imperative verbs
save: 'Lưu',           // Not: 'Lưu lại'
delete: 'Xóa',         // Not: 'Xóa bỏ'
create: 'Tạo',         // Not: 'Tạo mới' (unless needed for clarity)
update: 'Cập nhật',    // OK
cancel: 'Hủy',         // Not: 'Hủy bỏ'
```

### Messages
```typescript
// Success: Clear and positive
userCreated: 'Tạo người dùng thành công',
updateSuccess: 'Cập nhật thành công',

// Error: Specific and helpful
loadError: 'Không thể tải dữ liệu. Vui lòng thử lại.',
networkError: 'Lỗi kết nối mạng',

// Confirmation: Clear and direct
deleteConfirm: 'Bạn có chắc chắn muốn xóa?',
```
